# 我的博客上线了

今天把这个站搭起来了。起因是课程里要做一个能长期积累的个人知识库，我不想只交一个空仓库，就想着干脆做成自己以后也愿意打开的地方。

## 用了什么

- **Astro**：把 Markdown 变成静态网页，首页、归档、标签、关于和 RSS 都是自动生成的
- **GitHub Pages**：免费托管，不用买服务器
- **GitHub Actions**：每次推送后自动构建发布，我只要专心写文章

## 站上现在有什么

导航里的「归档」按时间排文章，「标签」按主题归类，右上角可以切换深浅色。第一篇《你好，世界》是测试渲染用的，接下来会慢慢换成真正的内容。

## 打算写什么

课程笔记、工具速查、踩坑记录，还有读到有意思的东西时随手记下的想法。先不追求写得多好，能持续记下来更重要。

这个站就叫 Featon，先从这三篇开始。
