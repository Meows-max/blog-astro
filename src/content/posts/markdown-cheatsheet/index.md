# Markdown 语法速查

这个博客的文章全是 Markdown 写的，把常用语法记在这里，忘了就回来翻。

## 基础写法

| 想要的效果 | 写法 |
|------------|------|
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 粗体 | `**文字**` |
| 斜体 | `*文字*` |
| 行内代码 | `` `代码` `` |
| 链接 | `[文字](网址)` |
| 图片 | `![说明](图片路径)` |
| 引用 | `> 引用内容` |
| 分割线 | `---` |

列表直接写就行：

```text
- 第一项
- 第二项
  - 嵌套项

1. 先做这个
2. 再做那个
```

代码块用三个反引号包起来，紧跟语言名可以高亮，就像这样：

```javascript
console.log('hello');
```

## 本站文章的特殊要求

每篇文章开头要有一段 front matter，用来告诉站点标题、日期和标签：

```text
---
title: 文章标题
date: "2026-11-17"
description: 一句话摘要
tags: [笔记, 工具]
draft: false
---
```

三个容易出错的地方：

1. `date` 必须写成 `"YYYY-MM-DD"` 并且**带引号**，站点会严格校验日期是否真实存在
2. `draft: true` 的文章不会出现在站点上，写完记得改成 `false`
3. 文章要放在 `src/content/posts/文章名/index.md`，是「文件夹 + index.md」的形式，不是单个 md 文件

图片和文件放在 `public/` 目录里，引用时路径前面要带 `/blog-astro/`。
